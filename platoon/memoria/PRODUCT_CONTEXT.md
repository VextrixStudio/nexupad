## Qué dice el README

NexuPad se describe como una aplicación multiplataforma, móvil y escritorio, para notas, organización y productividad. Las características que el README afirma son:

- notas
- calendario integrado, con eventos, tareas y recordatorios
- organización académica: materias, horarios y contenido de clases
- carpetas
- sincronización en la nube
- rendimiento

Los planes que el README nombra:

| Plan | Lo que el README le atribuye |
| --- | --- |
| NexuCore | Funciones básicas, anuncios mínimos, 5 GB, uso personal |
| NexuPlus | Lo de NexuCore, sin anuncios, 50 GB, mejor rendimiento |
| NexuPro | Lo de NexuPlus, máximo rendimiento, 200 GB, funciones avanzadas, prioridad de soporte |

El README anuncia como próximos: notificaciones inteligentes, automatización y personalización avanzada.

## Qué no dice esta ficha

No dice que esas funciones existan en código. La inspección de arquitectura, del mismo día, no encontró código. La especificación del pelotón añade, como terreno posible si ya estuviera en el repositorio: búsqueda, ajustes, preferencias, autenticación, notificaciones y otras funciones presentes. Hoy no están presentes.

No se ha elegido público más allá de lo que el README y la especificación dicen: una herramienta de productividad usable en móvil, tablet, escritorio y, cuando aplique, web responsive.

## Restricciones que ya vienen escritas

Mobile-first. Escritorio que no sea el móvil estirado. Liquid Glass solo como acento. Accesibilidad no opcional. No copiar interfaces propietarias. No reescribir a ciegas. Esas frases son reglas de la especificación, no hallazgos de investigación.
