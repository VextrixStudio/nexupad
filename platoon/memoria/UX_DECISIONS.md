# Decisiones de UX

No hay decisiones de UX. No se encargó a los cinco revisores. No hubo síntesis. No hubo `DESIGN_APPROVED`.

Lo que sigue no es una decisión de este pelotón. Es una restricción de la especificación, copiada para que no se confunda con un hallazgo:

- Mobile-first. El escritorio no es el móvil estirado.
- Breakpoints que habrá que definir cuando haya diseño: teléfono, tablet pequeña, tablet, portátil, escritorio, escritorio grande.
- Cada decisión visual futura se mide contra si ayuda a terminar la tarea más rápido, con más claridad o con menos esfuerzo.
- El tono pedido es limpio, premium, calmado, moderno, útil, enfocado, inteligente y ligero.
- No se copia la interfaz de una compañía. Los revisores extraen principios.

Cuando haya una decisión real, entra aquí con fuente, patrón, observación, decisión y adaptación a NexuPad. Sin esa cadena, no entra.
